# Record Store

중앙 DB 연결을 보여주는 직접 작성한 예제 프로그램입니다. 작은 문자열 기록을 이름으로 저장하고
다음 호출에서 조회합니다. `key`만 전달하면 조회하고 `value`도 전달하면 해당 기록을 교체합니다.

Agent Foundry의 별도 Worker가 전용 스키마와 계정을 만들고, 실행 환경에 연결 정보를 주입합니다.
비밀번호·서버 주소·스키마명을 직접 설정하지 않습니다. 테스트는 별도 임시 스키마에서 수행합니다.
운영 데이터는 프로그램을 다시 설치해도 보존하며 Git에는 저장하지 않습니다.

입력 예: `{"key":"greeting","value":"hello"}`
조회 예: `{"key":"greeting"}`
출력 예: `{"key":"greeting","found":true,"value":"hello"}`

프롬프트 예: `기록 greeting 저장 hello`, `기록 greeting 조회`.
플랫폼 내부에 포함된 `psycopg`를 사용합니다. 별도 PostgreSQL 컨테이너가 필요하지 않습니다.
한 워크스페이스에서 공유하는 기록이며, 사용자별 격리나 비밀정보 저장소를 제공하지 않습니다.
