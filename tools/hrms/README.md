# HRMS 인사·연차 관리

중앙 DB의 전용 스키마에 직원, 연도별 승인 연차, 휴가 사용 기록을 저장하는 기본 HRMS입니다.
등록과 조회, 부서 인원 및 전체 요약, 연차 잔여량, 중복 방지 휴가 기록을 지원합니다.
회사에서 확정한 연차 배정일수를 입력합니다. 법정 연차 자동 산정, 급여, 근태, 결재·SSO는 포함하지 않습니다.
인사 담당 관리자가 사용하는 로컬 MVP이며 운영용 개인별 접근 제어와 감사 정책은 별도 확장이 필요합니다.

프롬프트 예:

- `HRMS 직원 등록 DEMO001 가상직원01 개발팀 2025-01-01 2026 15`
- `HRMS 직원 DEMO001 조회`
- `HRMS 부서 개발팀 인원`
- `HRMS 연차 DEMO001 2026 잔여`
- `HRMS 휴가 사용 DEMO001 2026 0.5 신청001`
- `HRMS 인사 요약`
- `HRMS 도움말`

표시 이름과 부서는 공백 없는 40자 이하 문자·숫자·밑줄·하이픈을 사용합니다.
휴가는 0.5일 단위이며 사번별 요청번호를 재사용하면 중복 차감되지 않습니다.
동일 요청번호의 일수·연도 변경과 잔여량 초과는 거부합니다. 직원 재등록은 동일 정보에만 허용합니다.
연도는 명시적으로 입력하며 다른 연도 잔여량과 혼합하지 않습니다.
인사 요약은 부서별 최대 100개와 전체 직원 수를 반환합니다.

실행 계약: `run({"query": "직원 DEMO001 조회"}) -> {"answer": "...", "data": {...}}`.
CLI는 JSON stdin/stdout을 사용합니다. 플랫폼이 비루트 컨테이너, DB 연결, 제한 및 테스트 스키마를 관리합니다.
배포 시 manifest의 선언형 테이블과 일반 인덱스가 적용됩니다. 키 제약과 별도 DB 컨테이너는 없습니다.
직원·휴가 데이터는 Git에 저장하지 않습니다. 예제의 인물은 전부 가상입니다.
